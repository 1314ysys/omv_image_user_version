 OMV NAS 系统镜像 —— 使用说明
================================================================

一、这个包里有什么

  omv-nas.img               ★ 已解压好的系统盘镜像，逻辑 24 GiB（Rufus 直接用这个）
                             物理只占 13.6 GB（稀疏文件），SHA256 已校验通过
  omv-nas.img.zst           压缩包 3.95 GiB —— 用来分发给别人，对方自己解压
  omv-nas.img.zst.sha256    压缩包校验值
  NAS-交接文档.md            完整交接文档（功能来源、凭据、运维、坑）
  tools\zstd.exe            免安装 zstd（Windows 64 位），解压 .zst 用
  tools\解压稀疏.py          空间不足 24 GB 时的稀疏解压脚本（需 Python + zstandard）

  镜像内容：OMV 8.6 + Docker + 14 个容器 + 首启自动化
  引导方式：MBR / Legacy BIOS 与 UEFI（含 Secure Boot）都能起
  目标盘  ：≥ 24 GiB，建议 32 GB U 盘


二、写 U 盘（本机现在就能做）

  1. 插入 ≥32 GB U 盘（里面数据会被清空）
  2. 打开 Rufus（https://rufus.ie）
  3. 「设备」选 U 盘 → 「选择」选 D:\NAS-分发\omv-nas.img
  4. 分区类型 MBR，文件系统不用管
  5. 点「开始」，弹窗务必选「以 DD 镜像模式写入」
  6. 写入完成（24 GiB 数据，USB 2.0 约 20-40 分钟，USB 3.0 约 5-10 分钟）
  7. 目标机从 U 盘启动 → 首启脚本自动跑完初始化（约 15 秒）→ 控制台显示当前 IP


三、360压缩 能不能解压 .zst？—— 能

  你这台机器的 360压缩 4.0 自带 7z 内核 24.9.10，
  而 7-Zip 从 21.02 版起就支持 .zst，所以：
  右键 omv-nas.img.zst →「解压到…」即可。

  但要注意：解压出来是 24 GiB 的完整文件，需要目标盘有 24 GB 空闲。
  本机 C/D/E 都放不下，所以才预先做了上面那个 13.6 GB 的稀疏 img。

  其它能解压 .zst 的方式：
    · 7-Zip 21.02 及以上（推荐，免费）
    · 命令行：tools\zstd.exe -d omv-nas.img.zst
    · WinRAR 不支持 zstd，别用它


四、分发给别人——三种方式

  1) 移动硬盘 / U 盘直接拷
     拷 omv-nas.img.zst（3.95 GB）+ tools 文件夹 + 本文档

  2) 网盘
     传 omv-nas.img.zst（3.95 GB）。部分网盘免费账号单文件限 4 GB 以内，
     若被拒，可以拆成 2 个分卷，对方用命令行合并：
       copy /b omv-nas.img.zst.001 + omv-nas.img.zst.002 omv-nas.img.zst

  3) 局域网
     放到 NAS 共享目录或任意 HTTP 服务上让对方下载

  ★ 分发时只给 .zst，不要给 .img
    稀疏的 .img 一旦复制到 U 盘/网盘/exFAT 盘，会立刻膨胀成 24 GB。
    .img 只适合在本机原地交给 Rufus 写盘。


五、对方拿到压缩包后怎么用

  空间够（≥24 GB 空闲）：
    360压缩 或 7-Zip 右键解压 omv-nas.img.zst → 得到 omv-nas.img → Rufus 写盘

  空间不够：
    把整个文件夹（含 tools）放到有 Python 的机器上，执行
      python 解压稀疏.py D:\omv-nas.img
    它会跳过全零区块，只占约 13.6 GB，生成的 img 同样可以给 Rufus 用

  校验（可选但建议）：
    certutil -hashfile omv-nas.img.zst SHA256
    应为 2a799d76d8dcb57a38d8783856d39df92bffb625fcc6dd5edd27905a8133a1b6


六、首次开机（重要）

  镜像里没有数据盘，也没有首启标记，所以第一次开机会自动：
    重生成机器标识与 SSH 密钥 → 自动识别网卡名 → 强制改 root 密码
    → 改写配置里的 IP → 自动拉起全部 14 个容器

  控制台会显示当前 IP。root 密码 NasAdmin2026!（登录后强制改）
  OMV 面板 admin / NasAdmin2026!

  之后要自己接数据盘 → 建文件系统 → 建 mergerfs 池 → 配 SnapRAID
  （详见 NAS-交接文档.md 第 9.4 节）


七、常见问题

  Q: Rufus 提示「这不是标准镜像，是否以 DD 模式写入？」选什么？
  A: 选「是 / 以 DD 模式写入」。这是 raw 磁盘镜像，不是 ISO。

  Q: 开机黑屏 / 找不到引导？
  A: 确认目标盘 ≥24 GiB 且写盘用的是 DD 模式；BIOS 里 UEFI 和 Legacy 都能起，
     若 UEFI 下没启动项，进 BIOS 手动选 U 盘或打开 CSM。

  Q: 开机进系统但拿不到 IP？
  A: 首启脚本会自动适配网卡名。若仍未获取，控制台执行
     ip -br link  → 找到真实网卡名 → 改 /etc/network/interfaces
     → systemctl restart networking
